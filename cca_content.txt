
Exam Domains and Weightings

• Domain 1: Agentic Architecture & Orchestration (27%)
	• Designing and implementing agentic systems using Claude’s API
	• Managing loops, orchestration patterns, session state, and guardrails
	• Working with the Claude Agent SDK, hub-and-spoke multi-agent patterns, and programmatic enforcement hooks
• Domain 2: Tool Design & MCP Integration (18%)
	• Crafting effective tool schemas and selection descriptions
	• Implementing Model Context Protocol (MCP) servers and clients
	• Managing tool choice modes, error categories, and integrating external services
• Domain 3: Claude Code Configuration & Workflows (20%)
	• Configuring Claude Code for development workflows, settings, hooks, and permissions
	• Utilizing the CLAUDE.md multi-layer hierarchy (user, project, and path-specific rules)
	• Differentiating plan mode vs. direct execution, shared skills, and CI/CD pipeline integration (-p and JSON output flags)
• Domain 4: Prompt Engineering & Structured Output (20%)
	• Crafting high-performance system prompts with explicit criteria and few-shot examples
	• Implementing structured output patterns and tool_use JSON schemas
	• Setting up validation-retry loops and batch processing workflows
• Domain 5: Context Management & Reliability (15%)
	• Managing context windows, prompt caching breakpoints, TTL, and minimum thresholds
	• Handling long conversations, persistent case facts, and information provenance
	• Building resilient production systems with exponential backoff retries (e.g., handling 429/529 errors) and CI-gated regression evaluations
